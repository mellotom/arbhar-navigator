# arbhar-navigator

travelers guide for catching stardust: a one-page reference for the **instruō arbhar** granular audio processor, firmware 2.0. capture and accumulative recording, the six layers, the continuous and strike engines, window, direction, length, scan and spray, pitch deviation, onset modes, follow and wavetable modes, mod cv, the clone / load / save menu and every shift combo, with diagrams.

source: the instruō arbhar manual (firmware 2.0).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with instruō.
